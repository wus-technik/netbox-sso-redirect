# 1.0.0 — 2026-11-24

First stable plugin release for NetBox 4.7. This release preserves the existing SSO
redirect and emergency-login behavior and completes the security and English-language reviews.

## Changes since 0.3.0

- Translate documentation, package descriptions, comments, plugin UI, errors, and logs to English.
- Add eight security regression tests covering redirect targets, CSRF origins, GET start
  rejection, PKCE S256 session binding, HTTP methods, and unsafe session values.
- Restrict development NetBox and dummy IdP ports to localhost.
- Document dependency ownership and the security prerequisites for the hosting image.

## Compatibility and upgrade

- NetBox compatibility remains `4.7.0` through `4.7.99`; Python 3.12 or later.
- No new settings, database migrations, or plugin runtime dependency overrides.
- Install the release revision in the image, run `collectstatic`, and restart NetBox.
  The script URL now carries `v=1.0.0` to invalidate cached plugin JavaScript.
- `local_login` still defaults to `True`; explicitly set it to `False` to block the
  standard password login and token-provisioning routes.
- Plugin-owned messages are now English. Update external log filters that match German
  message text. Logger names, log levels, placeholders, HTTP statuses, and JSON keys are unchanged.

## Security scope and image prerequisites

The code review found no confirmed authentication bypass, open redirect, or XSS in
the plugin. **This release does not certify or patch the hosting NetBox image.**

The pinned development image contains `social-auth-core 5.2.0`, affected by
[GHSA-h2r5-x5m7-3935](https://github.com/python-social-auth/social-core/security/advisories/GHSA-h2r5-x5m7-3935).
Use a NetBox-compatible patched version (the advisory lists 6.2.0 as patched), or
enable `SOCIAL_AUTH_OIDC_USE_PKCE = True` with S256 and verify verifier enforcement
by the actual IdP. The plugin's PKCE test covers start parameters, not the full token exchange.

The same image contains Django 6.1.2, predating the
[Django 6.1.3 security release](https://www.djangoproject.com/weblog/2026/nov/03/security-releases/).
Check and update the production image's dependency versions as appropriate. Production
dependencies and effective PKCE configuration were not inspected during this review.

The operator reports successful production use on NetBox 4.7. Publishing this plugin
release does not deploy it or resolve the separate image findings.

## Validation

- Full suite against the pinned NetBox 4.7.3 image: 85 passed; four prefix-only tests
  skipped as expected and then passed separately with `BASE_PATH=netbox/`.
- Translation review: production Python control flow, JavaScript logic, template
  structure, configuration keys, and security boundaries unchanged.
- Release packaging: wheel and source distribution built and checked for version 1.0.0,
  the bridge template, and the static JavaScript asset.
