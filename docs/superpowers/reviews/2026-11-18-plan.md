# Review: implementation plan (2026-11-18)

**Scope:** Initial draft of `docs/superpowers/plans/2026-11-18-netbox-sso-redirect.md`
against the specification in `README.md`. Ref: ITSYS-422.

**Model/command:** Codex CLI 0.170.0, `gpt-6.1-sol`, medium reasoning,
`codex exec --sandbox read-only --cd <repo> --model gpt-6.1-sol - < <prompt>`.
The prompt used stdin because the Windows argument list was too long.
Checked against locally extracted NetBox v4.7.3, social-auth-app-django 6.1.0, and
social-auth-core 5.2.0 sources. Codex fetched Django, `netbox.plugins`,
`utilities/views.py`, and netbox-docker sources read-only from upstream.

**Result:** CHANGES_REQUESTED. The approach was sound, but one test was broken by
design, one manual step could not reach its destination, and several assertions
were incorrect or too weak. All 13 findings were accepted and the plan revised.

**Confirmed without changes:** social-core validates a POSTed `next` and stores it in
`session["next"]`; `SocialAuthBeginView` returns JSON containing `url` or `html`
and is not CSRF-exempt; NetBox uses `StaticFilesStorage`; `PYTHONPATH` plus
`INSTALLED_APPS` makes the plugin discoverable; `MiddlewareNotUsed` is appropriate;
HTML and JavaScript do not enter the wheel without package-data configuration.
